## Descrição

A máquina de perfuração de vidro automática, possui duplo cabeçote é adotada com sistema pneumático de aderência para fixar o vidro.

A mesa de trabalho pneumática para suporte de vidro de diversos tamanho é equipada com display para maior precisão e fácil operação. É uma das máquinas indispensáveis ​​na moderna indústria do vidro.
